Présentation de l'Application

Fonctionnalités

  • Prédiction du risque de fraude pour un contribuable individuel
  • Analyse par lot de plusieurs contribuables
  • Deux types de classification : binaire et multiclasse
  • Interface adaptée aux besoins de l'administration fiscale

Résultats de la Modélisation

Classification Binaire

  • Précision : 92%
  • Rappel : 88%
  • F1-Score : 90%
  • AUC : 0.95

Classification Multiclasse

  • Précision moyenne : 89%
  • Rappel moyen : 86%
  • F1-Score moyen : 87%

Documentation du Modèle

Variables utilisées :

Variable Description Valeurs possibles
Regime Régime fiscal du contribuable IGS, REEL
Persojuri Type de personne juridique Morale, Physique
gctax Groupe de compte de gestion Petits comptes, Grands comptes
Type de déclarant Type de déclarant des marchés publics Déclarants permanents, Défaillants
Conformité Conformité de déclaration 2023 MD, NPC, MND
MinCA23 Minoration du chiffre d'affaires 2023 Oui, Non
Nbprestation_marches Nombre de prestations de marchés Un marché, Deux marchés, Plus de deux marchés
Typedemarche Type de marché Bons commande, Lettre commande & Marchés, Mixte
DSF23 Déclaration sociale fiscale 2023 Oui, Non
MontantMP24 Montant des marchés publics 2024 (FCFA) Valeur numérique

Architecture Technique

L'application communique avec un service de calcul local.

  • Route prédiction simple : POST /predict-single
  • Route prédiction lot : POST /predict-batch
  • Modèles disponibles : Classification binaire (2 classes) et multiclasse (3 classes)
